# Khazar Quiz Platform

Khazar Quiz is a modern full-stack quiz platform developed with Spring Boot and Next.js.  
The project is designed with a premium SaaS-style interface inspired by the aesthetics of the Caspian Sea, combining dark and gold visual themes with smooth animations and advanced user interaction.

---

# Technologies Used

## Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Maven
- REST API

## Frontend
- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Recharts

---

# Main Features

## Authentication & Security
- JWT-based authentication system
- Role-based access control
- Separate permissions for Admin and User roles
- Improved admin account security

---

## Quiz System
- Interactive quiz participation
- Real-time scoring system
- Question-based answer tracking
- User performance analysis

---

## Scoring History
Users can:
- View previous quiz attempts
- Analyze performance history
- Review scores question-by-question
- Track overall progress

---

## Leaderboard System
- Dynamic leaderboard
- Ranking based on user performance
- Real-time score comparison between users

---

# Premium UI/UX Design

The platform follows a modern premium SaaS design philosophy:
- Dark & gold color palette
- Caspian Sea inspired aesthetics
- Fully responsive interface
- Smooth animations using Framer Motion
- Interactive charts and analytics with Recharts

---

# Database Seeder

The project includes a database seeder that automatically:
- Creates default admin accounts
- Inserts initial bot/sample data
- Prepares the system for first launch
